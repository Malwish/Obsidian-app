La función es como una maquina que toma un número y lo "Convierte" en otro. Se escribe de la siguiente forma: F(x) : .... o G(x): ..... para las funciones F o G relacionadas a la variable x, en este caso.

La definición formal es: Se llama función a una relación entre dos [[Conjuntos]] A y B que asigna a cada elemento de A un elemento de B. Formalmente se escribe F: A->B

[[Notación algebraica de símbolos]]: ∀a∈A, ∃! b∈B tal que (a,b)∈f
Donde:

- A es el [[Dominio]]
    
- B es el [[Codominio o imagen]]
    
- f es un **subconjunto de A×BA \times BA×B**

Por ejemplo: 

Una función es:

A{1;2;3;4}   B {2;4;6;8}

Siendo la función F: B es el doble de A. F{(1,2);(2,4)(3,6)(4,8)}

Una función es un tipo especial de relación binaria que cumple las siguientes condiciones:
1. Totalidad del dominio: Cada elemento de A aparece como primera componente de algún par.
2. Unicidad de la imagen: Ningún elemento de A puede estar relacionado a mas de un elemento en B.
