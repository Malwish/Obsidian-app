Los números naturales es un conjunto de números compuesto por todos los números positivos [[Enteros]], algunos matemáticos también incluyen el cero en los naturales, generalmente se hace la distinción de N para los números naturales sin el cero y N₀ (N sub cero) para los naturales con el 0 incluido.

 [[Notación de intervalos]] para este conjunto de números es : [1; INF)
