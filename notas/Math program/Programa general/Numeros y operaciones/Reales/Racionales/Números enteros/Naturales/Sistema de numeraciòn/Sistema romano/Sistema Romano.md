El sistema de numeración romano es un método de representación numérica que utiliza letras del alfabeto latino para denotar valores. Este sistema se basa en la acumulación de símbolos con un valor fijo, que se disponen de mayor a menor de izquierda a derecha. Los números romanos son no posicionales y utilizan siete letras mayúsculas: I (1), V (5), X (10), L (50), C (100), D (500) y M (1000). Este sistema fue utilizado durante el Imperio Romano y todavía se emplea en contextos específicos, como en relojes y numeración de siglos.
